# AlgoCraft promotional media

[Watch the English trailer](https://www.youtube.com/watch?v=DsKH72bj73o) · [English subtitles](media/algocraft-trailer-en.srt) · [Poster](media/trailer-poster.jpg)

The trailer introduces learning algorithms in Minecraft with real Java editing,
Run and Submit, 500 official problems, daily streak rewards and placeable trophies.
It supports Forge 1.20.1 / Java 17 and NeoForge 1.21.1 / Java 21, at 0.1.1 (Beta).

The film uses English captions, music and effects, with no narration. Native
Minecraft shots are camera moves over screenshots; calendars, reward cards and
server diagrams explain the mechanics. They do not represent extra in-game menus.

The [video project](../promo/video/README.md) contains editable source and
[asset credits](../promo/video/CREDITS.md). Finished artwork and the video are in
`docs/media/`. [Hosted image URLs](media/hosted-images.json) are available for
platform descriptions. The Minecraft computer icon has an editable
[SVG source](brand/algocraft-icon.svg).

Prepared platform descriptions: [English](CURSEFORGE.en.md) · [Chinese](CURSEFORGE.zh-CN.md).
