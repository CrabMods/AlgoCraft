# AlgoCraft

Learn algorithms in Minecraft: write real Java in an Algorithm Computer, solve the bundled 500-problem bank and earn survival rewards and placeable trophies.

[Download: CurseForge](https://www.curseforge.com/minecraft/mc-mods/algocraft) · [Modrinth](https://modrinth.com/mod/algocraft) · [Full guide](https://crabmods.com/mods/algocraft) · [Trailer](https://www.youtube.com/watch?v=DsKH72bj73o) · [简体中文](https://github.com/CrabMods/AlgoCraft/blob/1.21.1/docs/README.zh-CN.md)

## Features

- In-game IDE and a local browser IDE; English and Simplified Chinese.
- Public problems judged by the server, with examples and hidden tests.
- First-clear rewards, daily review rewards, streaks and engraved trophies.
- Server-managed problem banks; personal imports for unrewarded practice.

## Install and start

| Minecraft | Loader | Java |
| --- | --- | --- |
| 1.20.1 | Forge | 17 |
| 1.21.1 | NeoForge | 21 |

Install matching AlgoCraft builds on the server and clients. Craft the computer from 6 iron ingots, 2 redstone dust and 1 glass. Right-click it, choose an Easy problem, fill in the Java method, Run, then Submit.

The bundled bank and in-game IDE work offline. The Web IDE needs an active connected client and internet for its editor assets. Full-inventory trophies wait in the server mailbox; claim with `/algocraft trophy claim`.
